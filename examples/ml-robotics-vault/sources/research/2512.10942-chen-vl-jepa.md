## TLDR

VL-JEPA extends [[method:jepa]] to vision-language modeling: instead of a
classical VLM autoregressively generating response tokens, VL-JEPA predicts
a continuous embedding of the target text

## Contributions

- A vision-language JEPA that predicts target-text embeddings instead of
  generating tokens autoregressively, reportedly matching or beating
  standard token-space VLM training (same vision encoder, same training
  data) while using about 50% fewer trainable parameters
  [[raw:2512.10942#Abstract]].
- Selective decoding: because prediction happens in embedding space, a
  lightweight text decoder is only invoked when text output is actually
  needed, reportedly cutting the number of decoding operations by roughly
  2.85x versus uniform non-adaptive decoding at similar performance
  [[raw:2512.10942#Abstract]].
- Reports the resulting embedding space is directly useful beyond
  generation — open-vocabulary classification, text-to-video retrieval, and
  discriminative VQA without architecture changes — with average
  performance on eight video-classification and eight video-retrieval
  datasets surpassing CLIP, SigLIP2, and Perception Encoder, and comparable
  VQA performance to InstructBLIP/QwenVL despite only 1.6B parameters
  [[raw:2512.10942#Abstract]].

## Method summary

An x-encoder maps vision input $X_V$ to an embedding $S_V$; a y-encoder
maps the textual target $Y$ to an embedding $S_Y$; a predictor learns the
mapping $(S_V, X_Q) \mapsto S_Y$, where $X_Q$ is the textual query/prompt
[[raw:2512.10942#1-Introduction]]. The training objective is a distance in
embedding space, $\mathcal{L}_{\text{VL-JEPA}} = D(\hat{S}_Y, S_Y)$, rather
than the data-space objective $\mathcal{L}_{\text{VLM}} = D(\hat{Y}, Y)$ a
classical autoregressive VLM would use
[[raw:2512.10942#1-Introduction]]. At inference, a y-decoder reads the
predicted embedding $\hat{S}_Y$ out to text only when text output is
actually needed [[raw:2512.10942#1-Introduction]] — this is what makes
selective decoding possible.

The paper's stated motivation follows the same shape as every other JEPA
paper in this vault: predicting in embedding space means the model isn't
forced to reconstruct every surface-level detail of the target (word
choice, phrasing) the way a token-space VLM must, since semantically
similar but surface-different text targets can map to nearby points in
embedding space [[raw:2512.10942#1-Introduction]].
