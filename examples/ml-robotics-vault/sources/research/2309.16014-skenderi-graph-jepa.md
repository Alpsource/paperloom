## TLDR

Graph-JEPA applies the [[method:jepa]] framework to graph-level
representation learning: it masks subgraphs of an input graph and predicts
the latent representation of masked target subgraphs from a context
subgraph's representation, avoiding both the negative-sampling cost of
contrastive graph SSL and the overfitting tendencies of generative
graph-reconstruction methods
[[raw:2309.16014#Abstract]].

## Contributions

- Proposes Graph-JEPA, showing graph-level representations can be
  effectively modeled with the joint-embedding predictive paradigm
  [[raw:2309.16014#Abstract]].
- Introduces an alternative prediction objective: instead of regressing
  the target subgraph's embedding directly, the predictor targets the
  subgraph's coordinates on the unit hyperbola in the 2D plane, intended
  to endow representations with the implicit hierarchy common to
  graph-level concepts [[raw:2309.16014#Abstract]].
- Reports up to 2.5x faster training than Graph-MAE and 8x faster than
  MVGRL, while outperforming both on downstream graph classification,
  regression, and distinguishing non-isomorphic graphs
  [[raw:2309.16014#1-Introduction]].

## Method summary

The input graph is divided into subgraphs; a context subgraph's latent
representation is used to predict the latent representations of randomly
chosen target subgraphs, and the subgraph representations are pooled into
a graph-level representation for downstream use
[[raw:2309.16014#1-Introduction]]. Unlike a plain JEPA latent-regression
objective, Graph-JEPA expresses the target subgraph encoding as a
high-dimensional description of a hyperbolic angle, and the predictor is
tasked with locating the target in the 2D unit hyperbola — compared
against target coordinates derived from that same hyperbolic-angle
encoding [[raw:2309.16014#1-Introduction]]. `{{unclear-in-source}}` the
exact functional form of the hyperbolic-angle encoding wasn't captured
cleanly in the MinerU parse of this section; read
[[raw:2309.16014]] directly (§3, per the paper's own section numbering) if
that formula matters for your work.
